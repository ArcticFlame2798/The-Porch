# The Porch 🏡

**A place to connect, chat, and belong.**

The Porch is a real-time chat platform built around the idea of bringing people together in welcoming digital spaces. It lets users create and join communities, share conversations, and connect with others through a simple, warm, and easy-to-use interface.

## ✨ Features

- **Real-Time Chat** — Exchange messages instantly with other members.
- **Public and Private Rooms** — Discover open communities or join private spaces with authorized access.
- **Image Sharing** — Share images directly in conversations.
- **Room Management** — Create and manage rooms, control access, and customize room settings.
- **Join Requests** — Request access to rooms that require administrator approval.
- **Referral Access** — Invite others to private communities using referral codes.
- **Member Management** — Administrators can manage members, assign administrators, and handle bans.
- **Pinned Messages** — Keep important messages accessible in a room.
- **Live Presence** — See who's currently active in a room.
- **Typing Indicators** — Know when someone is composing a message.
- **Room Topics** — Give each community a description of its current focus.
- **Read-Only Mode** — Allow rooms to remain viewable while restricting new messages.
- **Personalized Profiles** — Customize your display name and emoji avatar.
- **Responsive Design** — Enjoy a clean interface across desktop and mobile screens.

## 🎨 Design Philosophy

The Porch aims to feel less like a crowded messaging platform and more like a familiar place where people can gather. Its warm visual style and straightforward interface keep the focus on conversations and community.

## 🛠️ Built With

- HTML
- CSS
- JavaScript
- Firebase Authentication
- Firebase Realtime Database

## 🌱 Our Vision

The Porch is built on a simple idea: every community deserves a place to gather. Whether it's a public conversation or a private group, the goal is to make connecting with others feel natural, comfortable, and accessible.
